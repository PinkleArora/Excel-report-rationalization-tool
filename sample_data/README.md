# Sample Data

Place representative `.xlsx` / `.xls` files here for development and testing.

**Do not commit real or sensitive business data.** Use anonymised or synthetic datasets only.

## Suggested Files

| File | Description |
|------|-------------|
| `sales_report_q1.xlsx` | Quarterly sales summary (synthetic) |
| `hr_headcount.xlsx` | Headcount by department (synthetic) |
| `finance_summary.xlsx` | Finance roll-up with overlapping columns (synthetic) |

These files will be used to demonstrate ingestion, profiling, schema matching, and consolidation.
